# ieSIM UI direction

ieSIM 的视觉语言来自三层关系：设备外框、SIM 芯片和无线连接。它强调清晰的资产关系，而不是复刻任何外部数据源的设备管理方式。

## 品牌

- 产品名固定写作 `ieSIM`。
- 主色为深翡翠绿 `#0B5D57`，深色基底为 `#073F3B`。
- 薄荷色 `#A9E6D5` 表示连接与安全，珊瑚色 `#F27457` 只用于需要关注的状态。
- 图标保持圆角、强轮廓和小尺寸可辨识性。

品牌概念图：[`iesim-brand-concept.png`](iesim-brand-concept.png)。正式应用图标由 Flutter 与 Android 原生矢量重新绘制，以保证深浅色和不同分辨率下清晰。

## 信息层级

1. 首页先回答“今天有没有需要处理的订阅”。
2. 添加订阅和扫码/导入是首页的两个主操作。
3. 设备空间按照 `设备 → 卡槽 → SIM/eUICC → EID → Profile → 订阅` 呈现。
4. SimHub、SimJ、Nekoko 和 LPA 只出现在“导入与导出”语境中，不影响主导航和资产结构。
5. 全部页面使用一致的 16–22 px 内边距、22–30 px 大圆角和状态色语义。
